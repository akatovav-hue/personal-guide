# День 2026-05-17 (Вс)

## Тактика дня

- **Окно:** 25+5 мин, одно конкретное время из weekly-слотов.
- **Действие:** выбрать один из двух методов (METHOD.001 запуск трекера + один метод по bottleneck = METHOD.003 медленное чтение).
- **Критерий закрытия дня:** слот отмечен в трекере. Не «сделал хорошо», а «сделал».

## Вопрос для чата с Claude Code в конце дня

«Слот закрыт / не закрыт — какое объяснение точнее описывает сегодня: ресурс, приоритет, ритм?»

Ответ не нужно записывать сразу как вывод — он копится в `history/` и используется Claude Code для корректировки следующего дня.
